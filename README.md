# AMRI VPN

AMRI VPN — Windows-first VPN-клиент с локальным адаптивным выбором маршрутов.

Главная идея проекта: пользователь не выбирает один VPN-сервер вручную. Приложение объединяет узлы из нескольких подписок в единый пул, измеряет качество каждого маршрута и локально выбирает лучший путь для конкретного сайта, приложения и типа трафика.

## Принципы

- Локальный интеллект без внешних AI API и облачных LLM.
- Несколько подписок одновременно без искусственного ограничения количества.
- Единый пул уникальных узлов с дедупликацией.
- Оценка не только по ping, а по latency, jitter, packet loss, TCP/TLS/DNS времени, пропускной способности, стабильности и истории отказов.
- Отдельная оценка `узел × назначение × профиль сети × тип трафика`.
- Разные маршруты одновременно для разных сайтов и приложений.
- DIRECT / VPN / BLOCK и резервные маршруты.
- Автоматический failover, quarantine/circuit breaker, hysteresis и confidence score.
- Локальная история обучения и возможность полного сброса.
- История сайтов и решения маршрутизации не должны покидать ПК без явного согласия пользователя.

## Структура проекта

- `crates/amri-core` — собственный движок принятия решений и модель маршрутов.
- `crates/amri-storage` — локальная память/история измерений.
- `crates/amri-subscriptions` — импорт нескольких подписок и нормализация узлов.
- `crates/amri-probe` — измерение качества маршрутов.
- `crates/amri-transport` — общий API жизненного цикла VPN-транспортов для Windows и Android.
- `apps/windows` — Windows-клиент и системная интеграция.
- `apps/android` — Android-клиент, VpnService lifecycle и платформенный UI.
- `docs/PRODUCT_SPEC.md` — единое техническое задание.
- `docs/DEV_JOURNAL.md` — журнал решений, выполненных работ и следующих шагов.

## Текущий этап

Первый этап создаёт независимое локальное ядро AMRI и его тесты. Сетевой транспорт, TUN, Windows Filtering Platform, DNS и протокольные адаптеры будут подключаться поверх стабильного API ядра, чтобы интеллект маршрутизации не зависел от конкретной реализации VPN-протокола.

## Статус

Проект находится в активной разработке.


### AMRI Route Proof

The shared Rust core can produce privacy-safe, tamper-evident local receipts for routing decisions. Raw destination and process identity are replaced by an installation-keyed pseudonym; receipts are hash-linked and can be verified or replayed locally for the “Почему?” screen.
