# AMRI Route Proof

AMRI Route Proof is a local, tamper-evident receipt for every routing decision. It makes an adaptive route auditable without exporting browsing identity.

## Receipt contents

- routing algorithm version;
- local creation time;
- HMAC-pseudonymized destination token;
- selected node identifier;
- decision reason;
- normalized score evidence for every recorded candidate;
- previous receipt hash;
- HMAC proof hash.

The host and process name are inputs only to a keyed local pseudonym. They are never stored in the receipt. Different installations produce unlinkable tokens for the same destination.

## Integrity model

Every receipt is authenticated with an installation-local 256-bit secret. Length-prefixed canonical fields prevent ambiguous encodings. Each proof includes the previous proof hash, so editing a score, changing the selected route, or removing an interior record is detected.

The secret must be generated by the operating-system CSPRNG and stored in Windows Credential Manager or Android Keystore. It is never federated or exported. `RouteProofChain` clears its in-memory key on drop.

## Product use

The “Почему?” screen can verify a receipt before displaying it, replay normalized evidence through another local scoring profile, and clearly mark broken history. Resetting learning intentionally starts a new chain.
