# AMRI UI Studio

Локальный визуальный редактор общей темы Windows/Android. Он не отправляет файлы или настройки в
интернет и работает в браузере на компьютере владельца.

1. Из корня репозитория запустить `python -m http.server 8080`.
2. Открыть `http://localhost:8080/tools/amri-ui-studio/`.
3. Визуально изменить цвета, скругление, отступы и размеры кнопок; переключаться между предпросмотром
   телефона и Windows.
4. Нажать **Скачать JSON** и заменить им `design/amri-ui-theme.json`.
5. Запустить `python scripts/generate_ui_theme.py`.
6. Проверить `python scripts/generate_ui_theme.py --check`, затем собрать обе платформы.

Абсолютное свободное перетаскивание блоков намеренно не экспортируется в приложение: оно ломает
адаптацию к разным разрешениям, длинным переводам и арабскому RTL. Положение меняется безопасными
responsive-параметрами. Для нового макета с другой иерархией можно сделать прототип в Figma или
Penpot, а затем один раз перенести структуру в `MainActivity.kt` и `main.rs`.
